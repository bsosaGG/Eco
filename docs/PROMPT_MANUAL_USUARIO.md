# Prompt One-Shot para Generación de Manual de Usuario

Copia y pega el siguiente prompt en tu asistente de IA (ChatGPT, Claude, etc.) para generar un manual de usuario profesional.

---

**Rol:** Eres un experto documentador técnico especializado en sistemas de gestión gubernamental y legal. Tu objetivo es crear un Manual de Usuario claro, conciso y visualmente organizado para el módulo "JurisGestión" del sistema SCSPR.

**Contexto:**
Acabo de desarrollar un sistema para la gestión de demandas y litigios (JurisGestión). El sistema permite:
1.  **Dashboard:** Ver estadísticas (Casos Activos, Sentencias, Contingencia) y lista de casos con filtros.
2.  **Caso Nuevo:** Formulario con pestañas (General, Narrativa, Estado/Finanzas) para registrar demandas. Incluye campos calculados y autocompletado de actores.
3.  **Detalle del Caso:** Ver y editar toda la info, ver historial, subir adjuntos, y ver una tarjeta financiera con impacto estimado.
4.  **Generación de Documentos:** Botón para exportar "Ficha del Caso" en Word (.docx) basado en una plantilla.
5.  **Configuración:** Subir y gestionar plantillas .docx.

**Instrucción:**
Genera un índice detallado y el contenido para el "Manual de Usuario - Módulo JurisGestión".

**Formato Requerido:**
*   Usa Markdown.
*   Incluye marcadores de posición donde debo poner las capturas de pantalla, así: `[INSERTAR CAPTURA DE PANTALLA: Dashboard Principal]`.
*   Divide el manual en estas secciones:
    1.  **Introducción** (Propósito y Acceso).
    2.  **Navegación General** (Menú lateral, Dashboard).
    3.  **Gestión de Casos** (Paso a paso para crear, editar y archivar).
    4.  **Gestión Documental** (Generar Word y subir adjuntos).
    5.  **Configuración** (Para administradores: plantillas).

**Tono:** Profesional, directo e institucional (Gobierno de Guatemala).

**Antes de generar el texto completo, por favor indícame qué pantallas o flujos específicos necesitas que te describa mejor o pruebe para asegurar que el manual sea preciso. Hazme una lista de 3 a 5 preguntas clave.**
